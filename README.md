# 💉 Vaccine Management System

This is a PHP & MySQL-based Vaccine Management System created by **Shoaib Khan** for managing vaccinations efficiently through three user roles: **Admin, Hospital, and Parents**.

## 🧑‍💻 Technologies Used
- PHP (Core)
- MySQL
- HTML5, CSS3, Bootstrap
- JavaScript
- Git & GitHub
- Admin Template: DarkPan
- Frontend Template: Medicio

## 👥 Roles & Features

### 👨‍⚕️ Admin
- Manage vaccines
- Manage hospitals
- View appointments
- View child details

### 🏥 Hospital
- Register hospital
- Update vaccination records
- Confirm or decline appointments

### 👨‍👩‍👧 Parents
- Register/Login
- Add child details
- Book appointments
- View vaccine reports

## 📂 Folder Structure
```
/vaccine-management
  ├── admin/          # Admin panel
  ├── hospital/       # Hospital dashboard
  ├── parent/         # Parent interface
  ├── assets/         # CSS, JS, images
  ├── db.php          # Database connection
  ├── index.php       # Main entry point
```

## 🚀 How to Run Locally
1. Clone the repo  
   `git clone https://github.com/Shoaibkhan-10/vaccine-management.git`

2. Import `database.sql` into phpMyAdmin

3. Start XAMPP/WAMP and run:  
   `http://localhost/vaccine-management/`
